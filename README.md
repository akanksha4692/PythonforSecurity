# Log Line Parser

A beginner Python project that parses cybersecurity log lines and converts them into structured dictionary data.

## Purpose

This project helps practice:
- String parsing
- Splitting and stripping text
- Dictionary operations
- Log normalization
- Basic cybersecurity automation concepts

# Common Log Formats To Support

## 1. Key-Value Logs
Commonly used in:
- firewalls
- EDR solutions
- network security devices

Skills required:
- string splitting
- dictionary handling
- field normalization

---

## 2. Linux Authentication Logs
Commonly used in:
- Linux servers
- SSH authentication monitoring
- system security logging

Skills required:
- pattern matching
- string parsing
- field extraction

---

## 3. JSON Logs
Commonly used in:
- cloud platforms
- APIs
- SIEM and SOAR integrations

Skills required:
- JSON parsing
- nested dictionary handling
- data normalization

---

## 4. CSV Logs
Commonly used in:
- exported security reports
- vulnerability scan results
- compliance reporting

Skills required:
- CSV parsing
- row and column handling

---

## 5. Web Server Logs
Commonly used in:
- Apache servers
- Nginx servers
- web application monitoring

Skills required:
- pattern recognition
- request parsing
- log analysis

---

## 6. Windows Event Logs
Commonly used in:
- Active Directory environments
- Windows servers
- authentication monitoring

Skills required:
- event field extraction

- normalization
